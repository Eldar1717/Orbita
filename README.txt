ORBITA / запуск на своём компьютере
Распакуйте архив. В терминале перейдите в каталог с server.py.
Для нейросетевых голосов установите зависимость и запустите сервер:
  python -m pip install piper-tts==1.8.0
  python server.py
Откройте http://localhost:8000 и разрешите доступ к микрофону.
Если не устанавливать Piper, в меню голосов можно выбрать «Системный».

Удерживайте пробел (вне текстового поля) или кнопку микрофона, пока говорите. Отпускание отправляет фразу. Новое удержание останавливает текущую озвучку и отменяет ожидание предыдущего ответа. При потере фокуса запись сбрасывается. Максимальная длина записи — 60 секунд.

Меню справа от микрофона: четыре русских голоса Piper, образец и темп. При первом обращении к каждому голосу сервер скачивает его с Hugging Face (около 60 МБ) в ~/.cache/orbita. После этого голос работает без интернета. В предпросмотре синтез выполняет сервер приложения; при локальном запуске — ваш компьютер.

Распознавание русской речи: Vosk в браузере. Архив включает vosk-model-small-ru-0.22 (Alpha Cephei) и vosk-browser 0.0.8 с меткой финального результата для push-to-talk (https://github.com/ccoreilly/vosk-browser). Звук микрофона не отправляется на сервер.
Для ИИ-ответов запустите Ollama или LM Studio и разрешите CORS с адреса приложения. Без модели работает демонстрационный чат.
Модели озвучки и карточки голосов: https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU
